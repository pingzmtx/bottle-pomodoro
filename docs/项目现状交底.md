## 一、这是什么

一个**单文件番茄钟**（品牌名「瓶子专注」，B 站 up 主「瓶子满天星」的作品）。

| 项 | 事实 |
|---|---|
| 交付形态 | **一个 `index.html`**（约 2.0 MB / 2,096,443 字节），双击就能用，无安装、无账号、无网络请求 |
| 数据落地 | 浏览器本地（IndexedDB 优先，localStorage 兜底），**不上传任何服务器** |
| 源码形态 | `src/` 多文件开发态 → 由 `tools/build.py` 合并成 `index.html` |
| 技术栈 | 原生 HTML/CSS/JS，**无框架、无构建依赖、无外部 CDN** |
| 目标环境 | 手机浏览器为主，含**较旧的安卓平板/WebView 内核**（这条很重要，见第五节） |
| 版本管理 | **无 git 仓库**。回退靠人工备份目录 |

**核心循环**：设定任务 → 开始一个番茄（默认 25 分钟）→ 中途可被"打断"并记录 → 完成/中断结算 → 沉淀成记录、统计、段位、树、成就。

**功能全景**（按代码实际存在罗列，不作评价）：

- **计时**：番茄钟、自由计时、模糊计时、休息（短休/长休）、打断记录与分类
- **计划**：待办、必做、习惯打卡
- **日志**：专注记录、日记
- **统计**：数据分析、种树、段位、成就、排行榜（5 个子标签）
- **设置**：时长、音效、通知、严格模式、极简模式、皮肤、数据备份/导入/导出/清理
- **附加系统**：沉浸式专注（剧本/冒险）、成长之旅（渐进解锁）、每周战标、金币兑换、海报生成、组队、机器人段位

## 三、内部结构

### 3.1 单文件是怎么拼出来的

`index.html` 不是手写的，是**模板 + 9 个脚本槽**按声明拼出来的：

```
src/template.html          ← 含占位标记 <!--@@__JSS_1__@@--> 等
        +
src/manifest.json          ← 声明每个槽装哪些文件、用什么标签包裹
        ↓  tools/build.py
index.html                 ← 单文件产物
```

- 槽位标记格式：`<!--@@__JSS_{n}__@@-->`
- 构建命令：`python3 tools/build.py`（合并）/ `--check`（只校验不写盘）/ `--lint`（语法检查）
- 反向操作：`python3 tools/build.py split`（把 index.html 切回 src/，仅在源码丢失时用）

### 3.3 五层架构（有可执行的门禁）

依赖方向**单向**，由 `tools/w6_layer.py` 静态扫描强制：

```
L0  00_pure_core            纯函数孤岛，不许依赖任何东西
L1  01a~01g                 引擎主干，可依赖 L0
L2  02/03/04/05/0E          增强层，可依赖 L0/L1，不许依赖 L3/L4
L3  06/07/08/09             横切基础设施，只可依赖 L0
L4  0A/0B/0C/0D             胶水层，最晚加载，不许被 L0~L3 依赖
```

- 实测：**层依赖硬违例 0 条**，软依赖 4 条（均为刻意的防御式 `typeof foo === 'function'` 判断）
- 违反层方向 → `w6_layer.py` 退出码 1 → 回归链 FAIL
- L2~L4 全部是 **IIFE 包裹**（`(function(){...})()`），内部实现不外泄，对外只挂特定 `window.xxx`
- 文件名含 `__wXXReady` 形式的幂等标记（如 `window.__w52Ready`），重复加载直接 return

### 3.4 页面与视图

页面是**单页多视图**。5 个视图 DOM 全在模板里，切换靠 class：

```
#view-timer   #view-plan   #view-log   #view-stats   #view-settings
```

- 切换函数：`switchView('名字')` —— **数据驱动**，内部就是 `document.getElementById('view-' + view).classList.add('active')`
- 底部导航 5 项（计时/计划/日志/统计/设置），写在模板 `nav.bottom-nav` 里，每项带 `data-view` 属性
- 统计页内部另有 5 个子标签（data/tree/rank/ach/lb），走另一套函数 `switchStatsSubTab()`
- 视图切换时有**副作用集**：进 `plan` 触发待办/习惯渲染，进 `stats` 重置到"数据分析"子标签等（见 `switchView` 函数体）

#### 4.2.1 smoke 在本机跑不了无头浏览器时：真机浏览器桥（2026-10-07 新增）

**先判环境，再决定绕不绕桥**：跑 AGENTS §2.8-12 的**三连自检**。
**完整 Linux / Docker 容器（`/dev/shm` 可写）能直接跑无头 CDP，别绕桥** —— 2026-10-12 实测
smoke **715/0**、e2e **77/0** 真跑（非 SKIP，且能出 PNG）。
只有确认起不来时（Android PRoot：`/dev/shm` 建不了、SwANGLE/Vulkan 初始化失败；或本机无 chromium），
smoke 才会以 SKIP 结束——而它是唯一能抓「点击 / 渲染 / 状态」回归的一段。此时才改走**真机浏览器桥**：

```bash
sh tools/smoke_via_browser.sh start    # 沙箱起桥，打印地址
# → 把内置浏览器导航到 http://127.0.0.1:8790/
sh tools/smoke_via_browser.sh tail     # 看进度 / 结果
sh tools/smoke_via_browser.sh stop
```

**传输**：页面轮询取命令 → 页内 `(0,eval)(expr)` → POST 回传结果。
`js()` 语义与 CDP 版一致，**断言一行不改**（避免"改测试让它通过"；条数不写死）。
`cdp()` 只有两处（视口切换），由外壳页调整 iframe 尺寸等价承担。

**这套跑出来是 99 PASS / 0 FAIL / 0 JS 异常**（2026-10-07 实测）。

**已知环境限制（必须在报告里显形，不许悄悄算通过）：**

| 现象 | 真相 | 处理 |
|---|---|---|
| 内置浏览器字体缩放 **1.45×**（html 23.2px，应 16px） | 应用 CSS 字号全是 px → 文字宽 45%，320px 下图表溢出 | 记「未验证」不下结论；缩放下的**通过**才记 PASS |
| 页面后台时定时器节流 **~2×**（实测 350ms→708ms） | 等待按固定秒数会在内容出现前判失败 | 用 `wait_until` 等**条件**，不猜秒数 |
| `location.reload()` 后旧文档可能取走命令却不作答 | 桥只保证送达，单发取值必然偶发失败 | 重载后的取值改重试 |

⚠️ **别拿内置浏览器量出的字号/尺寸当基准**——它有自己的全局缩放；判「变大变小」先问浏览器缩放。

## 五、已知约束与雷区（都是踩过的）

### 5.1 目标环境含较老内核

实际运行设备包括**较旧的安卓平板 / WebView**。下面这些在本项目里有真实事故记录：

| 现象 | 原因 | 项目现状 |
|---|---|---|
| 整个脚本 SyntaxError、全页瘫痪 | 老内核不认识可选链 `?.` | 全仓 `?.` 出现 **0 次**（曾专门清理 18 处） |

| 视口高度单位 | `dvh`/`svh` 老内核不支持 | 模板中 `dvh`/`svh` 出现 0 次 |

**语法现状实测**：全仓仍大量使用 `var`（保守 ES5/ES6 混写，非纯 ES5），但对"老内核直接崩"的语法已清零——**可选链 `?.` 全仓 0 次**（曾专门清理 18 处）。改代码时保持这一底线。

### 5.3 五个真实踩坑记录（来自 `ARCHITECTURE.md` §9）

1. **具名函数表达式陷阱**：`(function foo(){ setTimeout(foo,800) })()` 中 `foo` 外部不可见，抛 `ReferenceError` 且**静默中断其后全部语句** → 表象是"加载成功"实为半瘫痪。
2. **`appendChild` 已挂载节点 = 移动 + 失焦**：对已在 DOM 的节点无条件 `parent.appendChild(node)` 会触发 `blur()`，输入框丢焦点。必须用 `insertBefore`。
3. **无头浏览器 500px 最小宽度**：直接设 320 档会**假绿**（实际按 500px 渲染），必须走 CDP `setDeviceMetricsOverride` + 回读 `innerWidth` 断言。
4. **`Page.navigate` 销毁 JS 执行上下文**：之后所有 `Runtime.evaluate` 超时，必须重新 `Runtime.enable`。
5. **默认值不能写进用户偏好**：把"系统默认收起"落盘到 `uiPrefs.foldPrefs` 会吞掉用户手动展开偏好。正确做法是只登记标记、不落盘。

另有一条血泪教训：**批量改注释是高危操作** —— 删一行注释可能连带删掉注释块的 `*/`，导致后续代码被整个吸进注释、语法崩溃。已增设 `build.py --lint` 逐文件 `node --check` 兜底。

## 六、这套架构对"大改"的实际容忍度

只陈述机制事实，不作推荐：

**开放的地方**

- 视图是**数据驱动**：DOM 里放一个 `id="view-XXX"` 的容器、导航加一项 `data-view="XXX"` 并 `onclick="switchView('XXX')"`，机制上就通了 —— 但视图激活后的数据渲染、副作用、路由白名单、a11y、折叠记忆等都需要各自接上（`switchView` 内是一串 `if (view === ...)`）。
- 增强层全部 **IIFE + 包装式注入**，设计上"整段可回退"（注释原话）。
- 构建是**声明式**的，槽位顺序写在 `manifest.json`，加文件即加槽位。
- 有 9 段回归链 + 105 入口巡检，改完能自证。

**需要正视的事实**

- **`index.html` 不是手改对象**，任何改动都必须落到 `src/` 再构建。
- **路由白名单**：`0B_hash路由.js` 内硬编码 `var VIEWS = ['timer','plan','log','stats','settings']`，不在名单里的视图不进 hash 路由。
- **视图切换有硬编码分支**：`switchView` 里逐个 `if (view === 'plan')` / `'log'` / `'stats'` / `'timer'`，不是配置表。
- **导航容量**：底部导航当前 5 项（计时/计划/日志/统计/设置），模板中已存在一套**统计页内的子标签机制**（`stats-nav-item` + `switchStatsSubTab`）作为既有先例。
- **数据键不可随意改**：`tomato_focus_v3` 是存量用户数据的入口，改键名 = 用户数据全部读不到（除非写迁移）。
- **两种数据共存问题**：任何新增功能若也往 `localStorage` 写自己的键，会与 `appData` 单通道落盘机制并存 —— 本项目历史上专门做过一次"散键收编"（见 `uiPrefs`），是有先例的。
- **无 git**：没有版本回退兜底，回退靠人工备份。
