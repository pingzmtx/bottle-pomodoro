🎮 沉浸式专注 ▼

开启沉浸式专注
开始番茄时随机抽取角色卡，用剧情推进你的专注
玩法说明
展开说明
🎴 每次开始专注抽一张角色卡 → 4 个番茄 = 一章冒险（第一章 → 终章）
📖 短休时全屏展示剧情过渡页，番茄完成有角色台词
⚠️ 连续 2 个番茄未完成（含半个）将触发 Bad Ending 并重置进度
🎴 剧本抽取 ▶
固定副本＝内置剧本 + 你导入的副本，剩余概率生成随机剧本。点开可调固定/随机比例。
滑块越靠右越容易抽到固定副本（想刷某个特定副本就调高）；固定副本最高只能占 60%，至少保留 40% 随机新剧情。系统会尽量避免连续抽到你最近抽过的固定 / 随机剧情。
🎬 剧情副本 ▶
导入你自己的剧本，会进入「固定副本」抽卡池（固定/随机比例可在上方滑块自己调）。副本只存在本机，不随备份导出，不影响个人数据。

👻 过去的自己 ▼

显示「过去的自己」对比条
计时页展示某一天（去年今日 / 昨天 / 随机历史日）的专注量做参照。它只是记录，超不过不会影响任何奖励，也不会说你什么

展开说明

极简模式
展开说明
一键关掉种树、段位、成就等游戏化叠加层，回归纯粹计时器（工具优先，游戏为辅）。可在设置页随时关闭恢复。
打断宽容总时长（分钟，整个番茄共用）
展开说明
一个番茄内可多次打断，所有打断时间共用这一份总额度，不是每次单独分配。总额度内可恢复计时；超过则无法继续暂停，但完成时仍可按实际专注时长自选番茄类型。

展开说明
不收集任何东西
  • 没有账号不用登录，没有手机号邮箱可泄露
  • 没有服务器番茄、任务、日记、段位全在本机浏览器里，不上传
  • 没有埋点不接统计 SDK、不接广告，你的点击不会被记录
用到的浏览器权限
  • 通知番茄结束提醒，可随时在浏览器设置关掉
  • 剪贴板只在你点「复制」时写入
  • 屏幕常亮专注中防止息屏，退出即释放
什么时候会联网
  • 打开页面托管在 GitHub Pages（平台侧有常规访问日志）
  • 点「查看文档」跳转腾讯文档，由你自己决定要不要点
怎么删数据
  • 只删数据设置 → 数据备份与重置 → 清空全部数据
  • 彻底清除浏览器清除本站点数据即可，没有云端副本
